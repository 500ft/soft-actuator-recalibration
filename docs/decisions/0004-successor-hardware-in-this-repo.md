# Decision: successor hardware in this repository

## Status
Accepted 2026-11-08. Owner instruction 2026-11-08 (chat): commit McKibben successor hardware work to this
repository under `successor/` and publish it here.

## What was decided
- This repository is reopened for McKibben successor hardware only. Successor CAD, drawings, calculations,
  analysis inputs, results and their evidence go under `successor/`.
- New successor work lives here. The local successor repository named in decisions 0002 and 0003 remains the
  record of work before this date. Its notes move into `successor/` when the owner copies them.
- The owner approves public release in this repository of the successor CAD, drawings, calculations, analysis
  inputs and the copied successor notes. Decision 0003 authorized no publication; this record changes that for
  these files only. It does not approve a paper, preprint or other publication of successor results.
- Licensing for `successor/`: scripts and code under this repository's MIT License; CAD, drawings and documents
  under CC BY 4.0, as in LICENSE-docs.
- The first PR carries this record and changes only the separate successor section of ROADMAP.md, which points
  to `successor/`.

## What was not decided
- No physical work, purchase, fabrication, hardware testing or pressurization is authorized. No pressure part is
  released until the pressure qualification plan (P1-P7) is committed under `successor/`.
- The successor's public name stays pending.
- The closed study stays closed. Its results, manuscripts, CAD (including cad/reference-volume) and tests are
  unchanged, and v1.4 remains withdrawn.
- The pressure-sensor part and port remain owner inputs until the sensor audit (SENSOR_OPTIONS.md) is copied into
  `successor/`.

## Where the record lives
`successor/` in this repository. `successor/README.md` holds the part-number prefix (SAR), the part register and
the local CAD folder convention.
